# Reading Status

一个用于追踪与展示笔记阅读状态的 Obsidian 社区插件。它自动记录你打开笔记的次数、阅读时长、滚动进度（保留历史最大值）、已读与剩余章节、首次与最近阅读时间，并在状态栏与侧边栏仪表盘中展示。数据仅保存在本地插件目录，不联网、不上传；插件不修改笔记正文、不写入 frontmatter。

## 功能

- 阅读追踪
  - 打开、关闭、切换笔记时记录阅读会话。
  - 阅读次数去重：去重窗口（默认 5 分钟）内重复打开同一篇笔记计为一次，窗口可配置。
  - 空闲检测：窗口失焦超过阈值（默认 60 秒）的时间不计入阅读时长，阈值可配置；短暂失焦在重新聚焦时补记。
  - 记录总时长、单次会话时长、首次与最近阅读时间，重启后保留。
- 章节与进度
  - 解析 Markdown 标题，按配置的层级（默认 2 级，即 `##`）划分章节，代码围栏内的标题不计。
  - 章节身份为归一化标题文本，标题改名后旧记录自动失效，剩余章节数始终对应当前文档。
  - 基于滚动位置计算阅读进度，并保留历史最大进度（只增不减）。
- 统计
  - 单笔记：次数、时长、进度、章节、首次/最近阅读（仪表盘条目悬停可见首次日期）。
  - 全局：今日、本周（ISO 周，周一起始）、记录笔记数、累计时长。
  - 阅读最多排行、最近阅读列表，支持按文件夹或标签过滤。
- 显示
  - 状态栏常驻显示当前笔记摘要，例如 `阅读 3 次 · 12 分钟 · 46% · 剩 7 章`，可在设置中关闭。
  - 侧边栏仪表盘承载全局统计与列表，样式全部使用 Obsidian 内置 CSS 变量，深色模式无需额外配置。
  - 全部视觉标识为文字或 SVG 图标，无 emoji。
- 关系图谱着色
  - 在全局关系图谱中按阅读进度给笔记着色：未读为浅蓝，随进度加深，读完为深蓝，共六档。
  - 只重写图谱配置中的颜色分组（colorGroups），其余图谱选项与你手动创建的分组保持不变；插件自己的分组带内部标记，更新时只替换自己生成的分组。
  - 未创建的空双链节点不是文件，不会被分组命中，保持你现有的外观（如红色）。
  - 数据保存后按 30 秒节流自动同步；也可执行命令「更新关系图谱颜色」立即生效。
  - 局部图谱（单篇笔记的局部关系图）配置不在覆盖范围内。
- 数据管理
  - 导出为 JSON（写入仓库根目录 `reading-status-export.json`）。
  - 导入时校验 schema 版本并自动迁移旧版本数据，非 JSON、损坏数据或更新版本会被拒绝并提示。
  - 清理已删除笔记的记录；重置单篇笔记状态。
  - 文件重命名或移动时数据键即时迁移（含整文件夹移动）；删除的笔记数据保留至手动清理。
  - 每日聚合数据按保留天数（默认 0，永久）自动裁剪。

## 安装与构建

需要 Node.js 18 及以上。

```bash
npm install
npm run dev     # 开发监听构建
npm run build   # 类型检查 + 生产构建，输出 main.js
npm test        # 运行全部单元与集成测试
npm run coverage# 运行测试并输出覆盖率
```

手动安装：将 `manifest.json`、`main.js`、`styles.css` 复制到仓库 `.obsidian/plugins/reading-status/` 目录并在设置中启用。

## 使用

- 启用插件后，打开任意 Markdown 笔记，状态栏出现阅读摘要。
- 点击左侧边栏书本图标，或执行命令「打开阅读仪表盘」查看全局统计。
- 命令面板提供：导出阅读数据为 JSON、从 JSON 导入阅读数据、清理已删除笔记的阅读记录、重置当前笔记的阅读状态、更新关系图谱颜色。
- 仪表盘列表的每个条目右侧有「重置」按钮，点击后弹出确认对话框，确认后清除该笔记的全部阅读记录（次数、时长、进度、章节），状态栏、列表与图谱颜色随之刷新。
- 设置页覆盖：章节层级、去重窗口、空闲阈值、状态栏开关、排除路径（每行一个前缀）、数据保留天数，以及数据管理按钮。

## 数据与隐私

- 全部数据保存在 `.obsidian/plugins/reading-status/data.json`，由 Obsidian 插件接口（`loadData/saveData`）读写。
- 不联网、不上传任何数据；不修改用户笔记内容。
- 数据结构含 `schemaVersion` 字段，插件升级时按迁移链自动升级，拒绝比当前插件更新的数据版本。

## 手工验证步骤

以下行为依赖 Obsidian 运行时，无法在单元测试中覆盖，请在真实环境中按清单验证：

1. 启用插件后打开开发者控制台（Ctrl/Cmd+Shift+I），确认无报错。
2. 打开一篇笔记，状态栏出现 `阅读 1 次 · ...`；滚动到底部后进度百分比上升，回到顶部后百分比不下降。
3. 在 5 分钟内关闭再打开同一笔记，次数保持 1；等待超过 5 分钟再打开，次数变为 2。
4. 切换到其他应用超过 60 秒再回来，期间时间不计入；短暂切换（60 秒内）正常计入。
5. 重启 Obsidian，次数、时长、进度、章节与首次/最近阅读数据保留。
6. 重命名或移动一篇已记录的笔记，仪表盘中该记录的路径同步更新，历史数据不丢失；移动整个文件夹同样生效。
7. 删除一篇已记录的笔记，执行「清理已删除笔记的阅读记录」后记录消失。
8. 导出 JSON 后修改数据（如重置一篇笔记），再导入该 JSON，数据恢复到导出时状态。
9. 在设置中修改章节层级、去重窗口、空闲阈值、排除路径，行为随之变化；重启后设置保留。
10. 关闭「显示状态栏」后状态栏条目隐藏。
11. 切换深色/浅色主题，状态栏与仪表盘显示正常。
12. 打开全局关系图谱：未读笔记为浅蓝。阅读一篇笔记并滚动到中部，等待约半分钟（或执行「更新关系图谱颜色」命令）后回到图谱，该笔记颜色加深；读到最底部后变为最深一档。若图谱已打开且颜色未变，关闭再打开图谱。
13. 未创建的空双链节点保持原有外观（如红色），不受插件影响。
14. 在图谱设置中手动添加一个自己的颜色分组，执行「更新关系图谱颜色」后该分组仍存在。
15. 在设置中关闭「关系图谱着色」后执行更新，图谱恢复默认外观，且手动分组保留。
16. 在仪表盘任一列表中点击某条目的「重置」按钮：先弹出确认对话框；点「取消」不做任何事，点「重置」后该条目从列表消失、出现重置通知；若重置的是当前打开的笔记，状态栏摘要清零；图谱中该笔记在下次同步后回到最浅一档。点击按钮不应打开该笔记，Esc 应能关闭对话框。
17. 在移动端（若可用）验证打开笔记可记录次数与进度；移动端失焦事件精度有限，时长统计可能偏松。

## 已知限制

- 阅读进度基于滚动容器（编辑态 `.cm-scroller`、阅读态 `.markdown-preview-view`），折叠、分栏等特殊布局下进度是近似值。
- 章节位置按标题行偏移近似，与视觉位置可能有偏差。
- 空闲检测依赖窗口 blur/focus 与 visibilitychange；移动端后台切换的事件时机由系统决定，精度低于桌面端。
- 关系图谱着色通过写入全局图谱配置的颜色分组实现，Obsidian 未提供公开着色 API；若 Obsidian 更改分组格式，着色可能失效（其余功能不受影响），关闭该设置即可恢复默认。局部图谱不在覆盖范围内。
- 移动端建议先小范围试用；如遇异常可在设置中导出数据后备份。

## 开发

- `src/core/` 为纯逻辑（数据模型、迁移、阅读引擎、章节、进度、统计、维护、导入导出），零 Obsidian 依赖，全部有单元测试。
- `src/controller.ts` 编排事件到引擎再到持久化，依赖注入 `Host` 接口，集成测试使用 FakeHost。
- `src/main.ts`、`src/view/`、`src/settings-tab.ts` 为 Obsidian 接入层，按上文手工验证步骤验证。
- 测试命令：`npm test`；覆盖率：`npm run coverage`（核心模块行覆盖不低于 95%）。
